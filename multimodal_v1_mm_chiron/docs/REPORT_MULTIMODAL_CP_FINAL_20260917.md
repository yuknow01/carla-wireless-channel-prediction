## 7. 결론

1. **센서 정보는 채널 예측에 쓰이지 않는다.** 세 실험 27 개 멀티모달 run 전부에서 추론 시 센서 내용을 바꿔도 결과가 변하지 않았다(shuffle/foreign ≈ real). 위치는 내용 의존이 있으나 증분이 없어 공동적응이다.
2. **레이더를 넣고 학습하면 B1 에서 2 dB 좋아지는 현상은 실재(두 시드 재현)하나 학습 신호 효과이며, T1 에서는 나타나지 않는다.** 즉 처음 보는 장면으로 일반화하는 조건에서만 보이고 원인은 미확정.
3. **시간 분할(T1)은 카메라를 살리지 못했다.** RSU 시점이 전부 학습에 들어가도 카메라 증분 0·내용 무관. 9/11 미팅 가설(『기지국 단위 분할 때문에 이미지가 못 쓰였다』)은 이 데이터셋에서 성립하지 않는다.
4. **T1 이 B1 보다 3 dB 나쁜 것은 분할의 성격 때문**(궤적 꼬리 = 학습 때 지나지 않은 도로 조각)이며 센서와 무관하다.

미팅용 한 줄: 『분할을 시간 기준으로 바꿔도 카메라·LiDAR·레이더 정보는 예측에 쓰이지 않았고, B1 에서 보였던 레이더 학습 효과도 사라졌다. 센서 설치의 예측 성능 근거는 이 데이터에서 없다.』

## 8. 한계·주의

1. 실험 3 의 멀티모달 7 구성은 seed 42 단일이다(대조군만 3 시드). T1 σ(0.45 / 0.41 / 0.38 / 0.42)가 B1 의 약 2배라 판정 임계가 0.8~0.9 dB 로 넓다. 0.3~0.8 dB 의 작은 차이는 이 설계로는 판별 불가.
2. 부반송파 64개(7.68 MHz)는 결맞음 대역폭(8.8 MHz)보다 좁아 부반송파 축이 거의 평탄하다(`STANDARDS_CHECK_OFDM_20260911.md` §3-2). 논문 값 1024 로 바꾸면 절대값·모델 비용이 달라진다.
3. median NMSE dB 는 pooled(논문 표준에 가까움)보다 4~6 dB 유리하게 보인다. 외부 비교에는 pooled 를 쓴다.
4. 값은 전부 val 이며 test 분할이 없다. B1 val 은 3 장면, T1 val 은 궤적 꼬리 1.6~2.6 s 로 성격이 다르다.
5. 레이더 학습 신호 효과의 기제는 미확정. 판별 실험(레이더 캐시를 난수 토큰으로 바꾼 학습, B1, 약 15 h)은 미승인. 꼬리 편향 없는 블록 교차 분할, T1 레이더 시드 반복(2 시드 약 76 h)도 미승인.
6. 위치 브로드캐스트 3종(pos_true/pred/gps_bc)은 T1 에서 미실행(계획 §3 조건 미충족).
